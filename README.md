# Panicakes — кухня на Луне

Прототип для гейм-джема: 2D-игра на ~15 минут. Кухня на Луне с низкой гравитацией — продукты хватаются мышью
и подбрасываются. Дальше по плану: ветер, «поджаривание» солнечной радиацией при слишком высоком броске,
плита/кастрюля/блендер/нож внизу.

## Что нужно

- [Godot 4.7.2](https://godotengine.org/download) — обычная версия (**не .NET**), скрипты на GDScript.

## Как запустить

1. Godot → Project Manager → **Import** → выбрать `project.godot` из этой папки → **Edit**.
2. **F5** (Run Project). В редакторе игра открывается во вкладке Game, собранная игра — всегда в полный экран.

## Управление

- Зажать ЛКМ на продукте — схватить, тащить — перемещать.
- Резко дёрнуть мышью и отпустить — бросок по инерции; отпустить без рывка — просто уронить.
- Esc — выход.

## Структура

- `scenes/` — сцены: `main.tscn` (кухня), `item.tscn` + `items/` (продукты), `fx/` (эффекты ударов).
- `scripts/` — логика: бросок (`grabber.gd`), продукт (`item.gd`), сцена (`main.gd`), окно/выход (`app.gd`).
- `assets/sprites/` — SVG-спрайты, `assets/fx/` — частицы.
- `dev/` — тестовый харнесс (имитация мыши, скриншоты) и сценарии бросков; в игре без аргументов ничего не делает.
- `tools/` — скрипты проверки и прогонов (bash, macOS).

## Договорённости

- Имена файлов — строчными, `snake_case`: в собранной игре регистр в путях важен на любой ОС.
- Новые SVG в `assets/sprites/` импортировать как **DPITexture** (Import → Import As → DPITexture),
  иначе в полном экране будут мыльными. Частицы в `assets/fx/` — обычные текстуры.
- Файлы `.import` и `.uid` коммитить, папку `.godot/` — нет (она в `.gitignore`).
- Технические подробности (физика, тесты, арт-стиль, палитра) — в [CLAUDE.md](CLAUDE.md).
